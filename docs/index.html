IServiceAccountLayer

Narrow persistence interface for BaseCommandService.

The store exposes a layered model: an account layer carries the baseline config that survives across all sessions for a given account, and an optional session layer acts as an overlay on top that the running service writes to. Reads merge account ← session ← input; writes default to the session layer (so the account baseline stays stable). The /sconfig built-in writes to the account layer for persistent updates.
